# Eksport Nexus AI Mobile

To jest edytowalny projekt Expo/React Native wraz z backendem Express/tRPC.

## Uruchomienie

```bash
pnpm install
pnpm check
pnpm test -- --run
pnpm dev
```

Projekt zawiera cztery motywy, polskie UI, czat AI, załączniki, upload, transkrypcję głosu i lokalną historię. Wspólny backend udostępnia także klientowi webowemu procedury uploadu, czatu i transkrypcji.

Nie umieszczono tu `node_modules`, `.git`, logów ani sekretów.
